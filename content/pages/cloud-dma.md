# Cloud DMA for Caliber PC builds

Cloud DMA is a separate infrastructure license many Caliber listings require on supported Windows builds. It runs a Hyper-V environment on a single PC so compatibility tooling can load outside the game process.

## What you are buying

The listed **$50 lifetime** Cloud DMA license covers the virtualization layer—not the Caliber cheat subscription. Cheats and DMA are separate checkouts.

## Windows requirements

- Windows 10 or 11 64-bit with hardware virtualization enabled
- Sufficient RAM and CPU headroom for host + guest (see the setup guide)
- Administrator access to enable Hyper-V

## Additional costs

GREENWARD, static server hosting, and AWS resources are purchased separately from third-party vendors. Budget for those services before you enable Cloud DMA in production.
